# Strategic Decision Tool

A bilingual (Hebrew / English) field guide for running a structured strategic decision with an AI agent — built around a six-phase process (Frame, Generate, Evaluate, Challenge, Commit, Learn) and ready-to-copy prompts for Claude, ChatGPT, or Gemini.

Hebrew is the default view; switch to English with the language toggle in the top bar. The page is a single static HTML file: responsive, works offline once loaded (aside from the Google Fonts call), and has light/dark themes.

Adapted from Ross Dawson's original Strategic Decision Tool concept.
